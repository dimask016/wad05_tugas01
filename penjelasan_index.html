11–29 <meta http-equiv="Content-Security-Policy" content=" default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'none'; object-src 'none'; frame-ancestors 'none'; base-uri 'none'; form-action 'none'; worker-src 'none'; upgrade-insecure-requests; ..."> 🛡️ CSPLapisan keamanan utama. Default 'none' lalu whitelist ketat. Mencegah XSS, clickjacking, mixed-content, dan eksekusi resource eksternal. Mengizinkan style.css & script.js lokal
32 <meta name="referrer" content="no-referrer"> 🔒 PrivacyCegah kebocoran URL/referrer ke situs eksternal. —
35 <meta http-equiv="X-Content-Type-Options" content="nosniff"> 🛡️ MIME SniffingMencegah browser menebak tipe file (mis. file teks dieksekusi sebagai skrip). —
38 <meta http-equiv="X-Frame-Options" content="DENY"> 🛡️ ClickjackingFallback bila CSP tidak didukung — melarang halaman di-frame. —
41 <meta http-equiv="X-XSS-Protection" content="0"> 🛡️ XSSMenonaktifkan XSS auditor legacy yang justru bisa memicu bug (rekomendasi OWASP). —
44–57 <meta http-equiv="Permissions-Policy" content="camera=(), microphone=(), ..."> 🛡️ Feature PolicyMatikan API browser yang tidak dibutuhkan — kurangi attack surface. —
59 <meta name="color-scheme" content="dark"> 🎨 UIMemberi tahu browser bahwa halaman didesain gelap. —
60 <meta name="robots" content="noindex, nofollow, noarchive"> 🔒 PrivacyHalaman demo tidak diindeks mesin pencari. —
